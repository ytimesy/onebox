# 画面・操作仕様
## UIの原則
長い広告LPや管理画面を作らず、最初の画面から何をするゲームか分かるようにする。
仮のキャッチ: 「4つの形を、ひとつの箱に。」 / “Four pieces. One perfect fit.”
世界地図、架空の参加人数、架空のランキングは置かない。背景は控えめ、盤面と手元の4ピースを強調する。

## トップ
ヘッダー: 仮ロゴ、言語、設定。中央: キャッチ、3秒程度の任意デモ、今日の問題ID、開始ボタン。
サブテキスト: 「1分目標。時間が過ぎても続けられます。」
初回のみ「操作を試す」を副導線として提示。本番の開始ボタンを隠さない。
外部APIの集計や宣伝動画が読み込めなくても開始可能。

## プレイ画面（情報の配置）
```text
ONEBOX                  ?  設定
今日の箱 #日付          00:18

       5 × 5 の盤面

       4つのピース
       A / B / C / D

[回転] [置く] [戻す] [取消]
[ヒント]             [一時停止]
```
黒一色の小さなセルに意味を押し込めない。固定マスは斜線、ピースは色＋模様＋識別文字を使う。
日次のピース初期向き・配置順は全員同じ。言語切替で盤面を回転しない。

## 入力方式
### タップ/クリック（基本）
1. トレイのピースを選択。
2. 回転ボタンで90度回転。
3. 盤面セルをタップすると、そのセルを図形の左上基準とするプレビューを表示。
4. 「置く」で確定。無効な配置なら理由を表示し、盤面を更新しない。
基準点は図形の外接矩形の左上に表示し、空白位置が基準となる場合にも分かるようにする。
配置済みピースのタップで移動候補にでき、「戻す」でトレイへ戻せる。

### ドラッグ（ショートカット）
Pointer Eventsを使い、掴んだセルと基準点の差を保持する。スマートフォンでは指で図形が隠れないオフセット付きゴーストを表示する。
離したときに妥当性を検査して確定。盤外・pointercancel・スクロール中断なら元配置へ戻す。
ページ全体のスクロールやピンチズームを禁止せず、必要なピース操作領域にだけtouch-actionを適用する。

### キーボード
Tabでピース・ボタンへ。Enter/Spaceで選択。盤面では矢印で基準点移動、Rで回転、Enterで確定、Escで取消。
「戻す」「取消」「ヒント」は可視ボタンも提供し、キーボードだけに代替を限定しない。[S2]
短縮キーはゲーム領域にフォーカスがある時だけ働き、テキスト入力や支援技術操作を奪わない。

## レイアウトと見やすさ
320/375/390/768/1280 CSS px幅で確認する。主要操作は44×44 CSS px以上を目標に設計する。
これは製品独自の目標で、WCAG 2.5.8の24px基準と混同しない。[S3]
盤面セルは可能な範囲で48px以上を確保する。高さの低い端末で全内容の1画面固定を強制せず、必要な縦スクロールは認める。
ただし盤面と確定ボタンが使いにくく離れないよう実機で調整する。

描画はDOM/SVGを使い、可視フォーカス、行/列の読み上げ、選択ピースと配置可能状態の説明を用意する。
スクリーンリーダーには「3行2列、空き」「A、上から1列に3マス、中央から右へ2マス」のように図形/状態を説明する。
時間は毎秒読み上げず、完成や不正配置のみlive regionで控えめに通知する。
VoiceOver/TalkBackでの操作完遂テスト前に「完全対応」と宣言しない。
減らす動きの設定に従い、点滅・大きな揺れ・突然の音は使わない。効果音は初期OFF。

## 結果
メイン: 「ぴったり！」、完成状態。副情報: 任意で時間、ヒント、中断、初回/練習。
時間を非表示にした利用者の共有文へ勝手にタイムを含めない。
主ボタン「同じ問題を友達に送る」。副ボタン「もう一度練習」。当該問題が過去問なら「今日の問題へ」。
解けなかった場合は恥をかかせず「あと少し」「ヒントで続ける」「解答を見る」。未完成を完成として表示しない。

## 共有
共有シート前に結果カードの文字内容を確認可能にする。解答配置は含めない。
対応確認: navigator.share / navigator.canShare。ファイル非対応ならURL+テキストを共有する。[S1]
共有ダイアログのキャンセルはエラー扱いしない。クリップボードも失敗した場合は選択可能なテキスト欄を表示する。
画像はクライアント側で生成する静的な結果カード。Canvasだけに依存せずテキストの代替を残す。
共有成功表示は「共有先に渡しました」等とし「Xに投稿しました」と断言しない。

## 設定
日英、音、動きを減らす、時間表示、利用状況送信への任意同意、ローカル記録の消去。
記録削除は確認を1回行い、このアプリのキーだけを削除する。localStorage.clear()で他用途まで消さない。
