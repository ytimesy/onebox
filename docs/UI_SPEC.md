# 画面・操作仕様
## UIの原則
長い広告LPや管理画面を作らず、最初の画面から何をするゲームか分かるようにする。
仮のキャッチ: 「4つの形を、ひとつの箱に。」 / “Four pieces. One perfect fit.”
世界地図、架空の参加人数、架空のランキングは置かない。背景は控えめ、盤面と手元の4ピースを強調する。

## トップ
ヘッダー: 仮ロゴ、言語、設定。中央: キャッチ、3秒程度の任意デモ、今日の問題ID、開始ボタン。
サブテキスト: 「1分目標。時間が過ぎても続けられます。」
初回のみ「操作を試す」を副導線として提示。本番の開始ボタンを隠さない。
外部APIの集計や宣伝動画が読み込めなくても開始可能。

## プレイ画面（情報の配置）
```text
ONEBOX                  ?  設定
今日の箱 #日付          00:18

       5 × 5 の盤面

       4つのピース
       A / B / C / D

[回転] [置く] [戻す] [取消]
[ヒント]             [一時停止]
```
黒一色の小さなセルに意味を押し込めない。固定マスは斜線、ピースは色＋模様＋識別文字を使う。
日次のピース初期向き・配置順は全員同じ。言語切替で盤面を回転しない。

## 入力方式
### タップ/クリック（基本）
1. トレイのピースを選択。
2. 回転ボタンで90度回転。
3. 盤面セルをタップすると、そのセルを図形の左上基準とするプレビューを表示。
4. 「置く」で確定。無効な配置なら理由を表示し、盤面を更新しない。
基準点は図形の外接矩形の左上に表示し、空白位置が基準となる場合にも分かるようにする。
配置済みピースのタップで移動候補にでき、「戻す」でトレイへ戻せる。

### ドラッグ（ショートカット）
Pointer Eventsを使い、掴んだセルと基準点の差を保持する。スマートフォンでは指で図形が隠れないオフセット付きゴーストを表示する。
離したときに妥当性を検査して確定。盤外・pointercancel・スクロール中断なら元配置へ戻す。
ページ全体のスクロールやピンチズームを禁止せず、必要なピース操作領域にだけtouch-actionを適用する。

### キーボード
Tabでピース・ボタンへ。Enter/Spaceで選択。盤面では矢印で基準点移動、Rで回転、Enterで確定、Escで取消。
「戻す」「取消」「ヒント」は可視ボタンも提供し、キーボードだけに代替を限定しない。[S2]
短縮キーはゲーム領域にフォーカスがある時だけ働き、テキスト入力や支援技術操作を奪わない。

## レイアウトと見やすさ
320/375/390/768/1280 CSS px幅で確認する。主要操作は44×44 CSS px以上を目標に設計する。
これは製品独自の目標で、WCAG 2.5.8の24px基準と混同しない。[S3]
盤面セルは可能な範囲で48px以上を確保する。高さの低い端末で全内容の1画面固定を強制せず、必要な縦スクロールは認める。
ただし盤面と確定ボタンが使いにくく離れないよう実機で調整する。

描画はDOM/SVGを使い、可視フォーカス、行/列の読み上げ、選択ピースと配置可能状態の説明を用意する。
スクリーンリーダーには「3行2列、空き」「A、上から1列に3マス、中央から右へ2マス」のように図形/状態を説明する。
時間は毎秒読み上げず、完成や不正配置のみlive regionで控えめに通知する。
VoiceOver/TalkBackでの操作完遂テスト前に「完全対応」と宣言しない。
減らす動きの設定に従い、点滅・大きな揺れ・突然の音は使わない。効果音は初期OFF。

## 結果
メイン: 「ぴったり！」、完成状態。副情報: 任意で時間、ヒント、中断、初回/練習。
時間を非表示にした利用者の共有文へ勝手にタイムを含めない。
主ボタン「同じ問題を友達に送る」。副ボタン「もう一度練習」。当該問題が過去問なら「今日の問題へ」。
解けなかった場合は恥をかかせず「あと少し」「ヒントで続ける」「解答を見る」。未完成を完成として表示しない。

## 共有
共有シート前に結果カードの文字内容を確認可能にする。解答配置は含めない。
対応確認: navigator.share / navigator.canShare。ファイル非対応ならURL+テキストを共有する。[S1]
共有ダイアログのキャンセルはエラー扱いしない。クリップボードも失敗した場合は選択可能なテキスト欄を表示する。
画像はクライアント側で生成する静的な結果カード。Canvasだけに依存せずテキストの代替を残す。
共有成功表示は「共有先に渡しました」等とし「Xに投稿しました」と断言しない。

## 設定
日英、音、動きを減らす、時間表示、利用状況送信への任意同意、ローカル記録の消去。
記録削除は確認を1回行い、このアプリのキーだけを削除する。localStorage.clear()で他用途まで消さない。

## 2026-10-17 実装差分

配置候補に「置けます」または置けない理由を文字で表示。pointercancelに加えlostpointercaptureでドラッグを破棄し、別pointerの終了イベントを無視する。非表示/中断時は盤面・トレイ・ゴーストを隠す。

競合時は「このタブで続ける」を明示する。Web Locksの所有タブが応答しなければ無理に保存せず、元タブを閉じる案内を維持する。代替IndexedDBでは所有者tokenを更新し、旧所有者の遅延保存を拒否する。保存/排他が利用不可なら警告付き練習。

ローカルの結果共有はlocalhostの固定URLを使用し、「ローカル試遊用リンク（このPC用）」を含める。本番originをローカル試遊で達成したかのように案内しない。日次previewはローカル検証であることと版の日付を明示し、遅延/取得済み版からの新規挑戦は練習。実機/支援技術の完全対応とは報告しない。

### X投稿の主ボタン

結果の主ボタンは「Xに投稿 / Post to X」。まず投稿内容を確認し、同名の主リンクでX投稿画面を別タブへ開く（noopener/noreferrer）。最終投稿は利用者がXで確定する。投稿完了をONEBOXで表示しない。OS共有、文とリンクのコピー、手動選択、画像保存は引き続き利用可能。Xの外部スクリプトは読込まない。
## 2026-10-17 継続: 日次履歴（ローカル検証用）

daily-previewにも既存の「直近7回の記録」を接続。manifestの利用可能な問題をまたぎ、各UTC版の日付を固定URLへのリンクにする。練習も1回として数え、完了/未完了・解答表示・初回/練習・ヒント/中断・現地の開始日時・時間非表示を既存の表示と共用する。進行中は開く前に一時停止、閉じた後は明示再開。読込中は状態を伝え、閉じる操作で通信を中断できる。

未確認の問題があれば、その記録を表示できない旨と原本を削除していない旨を示す。取得不能を「参加なし」と誤認させない。固定公開版の「日次準備中」「次回未定」と当該1問だけの履歴は維持する。公開日次/実機受入済みとは表示しない。

## 2026-10-17 日次の撤回・全問利用停止（localhost検証）

利用できる日次問題がない場合は盤面や開始ボタンを表示せず、日英で「現在遊べる日次問題はありません。時間をおいて再確認してください。 / No daily puzzle is currently available. Please check again later.」と再読込ボタンを表示する。トップのHTTP状態は503、manifestは200で検査可能なunavailable。再確認で新しい受入済み問題が見つかった場合だけ開始へ戻る。

撤回済みの固定URLは410で、「この問題は公開を取り下げました。 / This puzzle has been withdrawn.」と44px以上の「トップへ戻る / Back to ONEBOX」リンクを出す。代替の過去問があれば日付/遅延/新規挑戦は練習の説明を維持する。保存済みの撤回問は新しい日次履歴から除外しても端末内の原本を消さない。読み込み済みの進行中runは別問題へ差し替えない。公開固定playtestの表示とXへの投稿確認は継続する。

## 日次の開始待ちと再確認（2026-10-17）

開始を押した直後から準備中として重複操作を防ぎ、日次の新規runでは公開状態の確認中と伝える。開始ボタンより下に状態を表示し、確認/失敗表示の出入りで開始ボタンを動かさない。確認中に操作練習や再挑戦を重ねない。再開にはネット接続を必須にしない。

撤回、掲載終了、検査失敗を日英で区別する。失敗時も記録を作らず、開始操作で再確認できる。公開中の問題を確認するリンクを添える。既に撤回/掲載終了を確認した問題では「新しい挑戦は練習になる」と約束せず、開始できないと表示し、結果共有導線も隠す。完成済みの結果そのものは保持する。

トップ更新後の古い画面では「新しい問題が公開されています。この画面の問題で新しく遊ぶ場合は練習になります。 / A new puzzle is available. New attempts on this screen are practice.」と伝える。固定ID/hashを保って開始し、利用者が公開中の問題へのリンクを選んだ場合だけ新問を読み込む。未確認の新問公開や次回時刻を作らない。

## 180問を超えた固定URLと履歴（ローカル検証）

recent外の過去固定URLでは、manifestが参照する索引のhashを確認し、指定された同じ問題を表示する。見つからないURLを現在問へ差し替えない。索引失敗・不正・4xxは既存のエラー/明示再確認、撤回URLは410と日英トップリンクを使う。通信失敗時に検証できる取得済み版がある場合だけ練習へ退避する。

直近7回の履歴も全公開アーカイブのメタデータを参照し、recent外の参加を固定URLで表示できる。未確認分は警告して原本を保持し、確認中は従来どおり一時停止する。撤回問を履歴から省いても保存runは消さない。結果共有も対象問題の固定URLを使い、現在問のURLへ置き換えない。索引や未来候補の一覧を画面へ羅列しない。
