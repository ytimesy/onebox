# ゲームルール・状態遷移
## 座標と図形
xは右向き、yは下向き、左上は(0,0)。盤面は0〜4。各ピースは5つの異なる整数座標を持ち、上下左右に連結する。
ピースの最小x/min yがともに0となるよう正規化する。回転は `(x,y) -> (-y,x)` 後に正規化する90度時計回り。
画面座標ではyが下向きであることに注意。回転4回で元の形に戻る。裏返し操作は実装しない。
回転で同じ形になる向きはソルバー内で重複除去する。

4ピースは回転・鏡映を考慮しても別形とする。これは見分けと解数判定を簡単にするためのv1制約である。
固定マスは5つ。空き20マスは連結。各ピース5マス×4=20。

## 正しい配置
`Placement = {piece_id, rotation:0|1|2|3, x:int, y:int}`。
x/yは回転後のバウンディングボックス左上。実際にそのセルが図形に含まれなくてもよい。
置く前に、盤外・固定マス・他ピースとの重なりをすべて検査する。
移動中の元ピースは衝突検査から一時的に除外し、確定までは元配置を保持する。
失敗時は元配置へ戻す。無効配置で盤面を部分更新しない。

完成判定は、4IDが1回ずつ、各形が許可された回転、25マス内、重なりなし、固定5マスを回避、空き20マスを完全被覆していること。
保存解との文字列一致で正解判定しない。生成側の見落としで別の合法解があっても、合法な完成を拒否しない。

## 状態
`loading -> ready -> playing -> completed`
`playing <-> paused`、`playing -> revealed`、エラー時は`error`。
60秒到達は状態終了ではなく `overtime=true` のフラグ変更だけ。

- loading: 必要JSON・CSS・描画準備が終わるまで操作と時計を開始しない。
- ready: 説明と開始ボタン。日次の盤面/ピースは開始時に提示する。
- playing: 移動、回転、取り消し、ヒント、時間表示切替。
- paused: 盤面とピースを覆う。再開ボタンを表示。
- completed: 入力を停止し結果を保存。取り消しで初回結果を消せない。
- revealed: 明示確認後に解答を表示。completedには数えない。

## 時計
描画準備が完了し、開始操作後に問題を表示するフレームをt0とする。
`performance.now()`ベースの区間時間を積算し、タイマー表示のsetInterval回数を時間の真値にしない。
500ms目安と確定操作時に途中状態を保存する。隠れたタブ、手動一時停止、再読込での復帰は中断フラグを付ける。
時計リセットや不自然な時計ジャンプを検出した場合は `clock_status=uncertain`。遊びは継続できる。

- active_elapsed_ms: 表示中でplayingの区間の合計。
- interrupted: 手動停止/非表示/復帰があったか。
- clock_status: continuous / resumed / uncertain。
- timer_visible: 表示だけの設定。falseでもゲームのルールや問題は変わらない。
- first_attempt: 端末内でそのID+rules_versionに対する最初のrun。

60秒タグの条件: first_attempt AND completed AND hint_count=0 AND interrupted=false AND clock_status=continuous AND active_elapsed_ms<=60000。
境界は59,999 / 60,000 / 60,001msでテストする。秒丸めは表示だけで、判定はmsで行う。
称号は自己記録。改造クライアントの時計を証明できるものではない。

## 取り消し・再挑戦
確定した配置/削除/回転を履歴に積む。無効ドロップは積まない。
プレビュー中の回転は未確定操作であり、取消は選択開始時の状態に戻す。
最初からやり直す操作は新しい練習runを作る。初回runの記録、ヒント、中断は消さない。
初回runを途中終了した場合はローカルで `abandoned` とし、後のrunを初回扱いにしない。
ブラウザーデータ消去による再初回化は防げない。世界ランキングを設けない理由の一つとする。

## ヒント
無料でいつでも利用可能。利用者が押す前に助言を出さない。
本番ソルバーはWeb Worker内で実行し、探索限界超過時は「ヒントを準備できませんでした」としてプレイを続ける。
ヒントボタン押下だけではカウントせず、解答情報を表示したときに増加する。

一意な全体解を取得した上で:
1. 現在の配置に全体解と異なるピースがある場合、ID順の先頭を示して「このピースを戻して考えてみよう」。自動削除しない。
2. 誤配置がなければ、未配置のID順先頭1ピースの置き場所をゴースト表示する。
3. ゴーストは通常のプレビューとは見た目を分ける。ヒント利用済みフラグは取り消しで戻さない。

公開JSONに保存解を含めない。ただしルール・問題・ソルバーがブラウザーにある以上、解答を絶対に隠せるわけではない。

## 更新・保存復旧
プレイ開始時の問題ID、内容ハッシュ、rules_versionをrunへ固定する。
更新で別問題を差し込まない。同じ問題で別タブが操作中なら、二重保存を避け、開き直した側に継続先を選ばせる。
保存データはスキーマ・座標・ハッシュを再検証。壊れた記録だけを隔離し、新しいゲームまで使用不能にしない。
ブラウザーが保存を拒否した場合はメモリー内で続け、結果は今回限りであると説明する。[S7]
